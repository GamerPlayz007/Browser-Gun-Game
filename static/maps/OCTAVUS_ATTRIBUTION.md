# Red Eclipse 2 — Octavus map (visual prototype)

This folder includes a converted map geometry preview of **Octavus**, an arena appearing in Red Eclipse 2. Its geometry is sourced from the OBJ export in https://github.com/Calinou/game-maps-obj/tree/master/redeclipse and the Red Eclipse map project https://github.com/redeclipse/maps .

Original map creators: Ricky "unixfreak" Thomson and Alex "molexted" Foster (as credited in Red Eclipse's Octavus documentation). The source export identifies Octavus under **Creative Commons Attribution-ShareAlike 3.0** (CC BY-SA 3.0).

Any redistributions or changes of this adapted map should retain attribution, license notice, and indicated changes. The imported asset is a geometry-only copy converted to compact binary data for loading within CROSSFire's rendering environment. This is not a copy of Red Eclipse code, branding, weapons, sounds, or gameplay logic. Replacement procedural appearance is original to CROSSFire; textures and props are not copied from Red Eclipse.
