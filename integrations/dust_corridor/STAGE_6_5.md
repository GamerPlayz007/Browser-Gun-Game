# Stage 6.5 — native multiplayer Dust Corridor

## Architecture

- The same CROSSFire game page, renderer, Three.js camera, HUD, player models, weapons, scoreboard, room codes, and network transport now support **Dust Corridor** as a third selectable multiplayer map.
- `build_map.py` compiles map JSON from the pinned `DUSTCOL3` original triangle mesh and source-validated A/B spawn positions. `static/maps/index.json` is generated by the authoritative compiler, not patched by hand.
- `static/dust_match65.js` generates **all five original geometry batches**, cloth/cables and building facades with the original authored `MapGenerator`. It renders through the existing CROSSFire scene/postfx pipeline, not an iframe or separate game loop. Surface rendering uses the adapted Stage 6.2 shader fallback; original high-quality procedural materials are still a Stage 6.7 fidelity task.
- `dust_motion65.py` + `static/dust_motion65.js` implement fixed 60Hz per-map triangle/capsule movement, sharing formula constants and calling the exact original source triangle collision geometry. They preserve walking, sprinting, jumping, crouching and sliding. More elaborate mantle/wall-kick features remain handled by the box-map engine and need map-specific follow-up if desired.
- The Dust server validates the full original triangle mesh for LOS, gunfire occlusion, ground probes and spawn walls. Its original source play bounds remain authoritative.
- The ordinary matchmaking lobby can select Dust, using multiplayer player-spawn history and automatic authoritative snapshots/input replay.
- `static/minimap.js` uses source-generated building footprints in the existing HUD, including the original A/B spawn groups.

## CI/release gates

- Both original source-ray and Python geometry probes are compared.
- `gen_dust_replay65.mjs` exports deterministic client prediction trajectories, which Python replays for tick-by-tick source mesh parity checks.
- Tests cover old maps, new room WebSockets, exact cover hits, boundaries, spawn safety, single-renderer original-geometry loading, match setup and remote peer synchronization.
- Old Daybreak/Neon fields, independent map scenes, assets and match options are left intact.

## Remaining

Stages 6.6 (low-end FPS/loading) and 6.7 (visual fidelity and extended playtests) remain, and UI/physics issues found on real school laptops may need tuning.
