# CROSSFire · AETHER-9 SPECTER — Phase 1.4 Asset Organization

**Scope:** Original fictional science-fiction game art. This phase makes an artist-editable Blender source and a machine-readable GLB easier to reuse. It does **not** replace the current multiplayer weapon or implement real-world mechanisms.

## Asset contract

The Blender scene now has a stable scene root, `A9.ROOT.SPECTER`, and eight semantic subcollections. Each collection contains a named `A9.GRP.*` empty parent and its related sculpted game-art objects.

| Group | Purpose |
|---|---|
| `SHELL` | Main silhouette and sculpted composite body |
| `SPINE` | Continuous artistic crown and lightline |
| `PANELS` | Floating sculpted side plates and fin shapes |
| `REAR` | Open-frame rear silhouette and decorative highlights |
| `VISOR` | Fictional optical ornament |
| `CORE` | Luminous abstract internal centerpiece and glass |
| `GRIP` | Matte lower support and decorative ridges |
| `ACCENTS` | Labels, light marks, and small ornamental details |

**Naming:** `A9.<GROUP>.<L|R|C>.<NUMBER>.<SHORT_DESCRIPTION>`. An immutable label is saved in the Blender object property `aether_source_label`, with `aether_group`, `aether_asset`, and `aether_uv_state`. Selected extras are passed through glTF when supported by Blender.

**Coordinates:** Original authored meshes remain in world space when parented. Blender's coordinate conversion is preserved, and no art pieces are allowed to move during grouping.

**Material slots:** Nine established material families (ceramic, alloy, gunmetal, polymer, silver, cyan, glass, copper, carbon). The Phase 1.4 script records their names in the exported manifest rather than baking them into textures.

## Quality gates

1. Save and validate a native Blender scene and a glTF 2.0 binary asset.
2. Manifest references exactly eight nonempty semantic groups and all source objects.
3. No duplicate semantic IDs, missing exported group anchors, or missing GLB meshes.
4. After grouping, every visual object's world-space position is unchanged.
5. Three image-review angles must remain nonblank, with adequate frame size.
6. Previous multiplayer model assets and controls remain unchanged.

## Readiness for Phase 2

Phase 1.4 is **asset structure**—not professional UV unwrapping or texture baking. Phase 2 should inspect mesh topology, distinguish true hard edges from smooth ones, assign dedicated UV islands with padding, and ensure detail maps can be baked without material mismatches. Texture bakes and optimized LODs are separate later milestones.

**Reviewer note:** The export manifest and report are generated by CI when the Blender build passes. Source-code changes alone are not proof of a completed scene export.
