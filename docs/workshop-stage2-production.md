# CROSSFire Workshop / Phase 2 Stage 2 — Production workbench

## What is working in the Workshop
The **COMPARE TWO VERSIONS** button opens a full-window production comparison inside /static/workshop.html. Select two catalog models and profiles, including personal GLBs previously stored in this browser. The WebGL renderer uses two independent asset scenes, a single synchronized camera orbit/zoom and side-by-side scissor rendering. Each side reports meshes, triangles, UV presence, materials, textures, bones and animation clips. Export JSON captures both source file sizes and original dimensions.

Both sides are normalized for display. The visually displayed scale does **not** compare physical size. Normalizing makes material, geometry and shape differences easier to inspect; original raw dimensions appear in the JSON export.

The Workshop's original garage remains the main page. Comparison is an overlay; closing it returns to the workbench. Workbench FPS sampling pauses behind the overlay to avoid double rendering.

## Licensed industrial environment source — Lantern
A textured artist-created old wooden street light model, not generated by the Workshop.
- Model source and directory: https://github.com/KhronosGroup/glTF-Sample-Assets/tree/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models/Lantern
- Model artwork license: CC0-1.0; official source LICENSE.md.
- Initial model artist sbtron (Microsoft, 2017), glTF conversion Frank Galligan (2018).
- Pinned source GLB: https://raw.githubusercontent.com/KhronosGroup/glTF-Sample-Assets/e124e8d8d7330a5372bc2b4d00d39a4a9d7997ea/Models/Lantern/glTF-Binary/Lantern.glb
- Expected file length: 9,564,264 bytes. Git blob SHA1: 0c97893aee066b6fa36f7725443b7536c3510d09.

**Note:** The binary was not downloadable in this tool environment, and Blender is not installed here. The source is prepared with a pinned URL, license, checksum, and a Blender production script, but no .blend or reduced GLBs have been generated or validated yet. These outputs must not be represented as complete until the script actually runs.

Run on a computer with Blender 4.x installed:

    blender -b --python tools/blender_lantern_stage2.py -- --out artifacts/lantern

For offline inputs supply --source /path/to/Lantern.glb. The script validates the pinned source bytes, imports the original mesh, saves an editable Blender source and Hero GLB, then reloads the source and exports a lower-texture/optional reduced-poly Performance copy. A JSON report records the changes. Review the output for UV, material, normal and visual fidelity before use.

### Quality gates before actual map integration
1. CC0 provenance and source checksum verified.
2. Blender import, export and Hero/Performance variants visually inspected.
3. Side-by-side Workshop comparison reviewed.
4. School-laptop FPS and GPU draw calls measured in a real browser.
5. Only then promote an environmental asset to Daybreak City (not part of this stage).

No networked gameplay, weapon code, server, physics or collision files are modified.
